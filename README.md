# 墨绘战场

以 Opus 5.5 为主的细铅笔线稿、暖色纸张、少量蓝色标记与持续积累的厚实墨色。电脑浏览器 FPS，支持单机三章闯关、单人电脑双队涂地和 2–8 人局域网竞技。原来的两个 Demo 保留在上级目录，新工程独立运行。

[在线体验](https://ink-battlefield.vercel.app/) · [GitHub 源码](https://github.com/SiyanHub/ink-battlefield)

## 启动

Vercel 发布使用 `npm run build:cloud`，当前源码的云端构建提供单机战役、单人电脑双队涂地和自由试笔；单人涂地无需房间服务器。该构建在局域网页展示启动说明，不连接站点上的 `/ws`。本地构建 `npm run build` 保留完整局域网房间功能。当前房间状态位于独立 Node 服务的内存中，本次不把它迁移成公网房间服务。在线站点使用云端构建，局域网房间仍需本机启动服务。

安装 Node.js 22.12+（开发验证为 24.14.0），在本目录打开 PowerShell：

```powershell
npm ci
npm run build
npm start
```

浏览器打开 **http://127.0.0.1:8903/**。也可以双击 `启动单机.cmd`（或右键运行 `启动单机.ps1`）；脚本自动检查依赖并构建。不要直接双击 index.html。

开发：`npm run dev`，地址 http://127.0.0.1:8902/。开发服务器只监听本机；连接房间仍需单独启动游戏服务。

局域网主机双击 `启动局域网.cmd`（或运行 `启动局域网.ps1`），也可以：

```powershell
npm run build
npm run start:lan
```

服务输出该电脑的局域网地址，例如 `http://192.168.1.20:8903/`。所有玩家用自己的电脑打开该地址，进入“局域网对战”。房主创建房间并分享房间号，其他玩家填号加入。选择模式/地图/队伍、职业和画具后，每个人点击“确认装备 · 准备”，房主开始。团队模式需要两队都有人，至少两位真人。单机解锁不限制竞技装备。

无法连接时检查同一局域网、地址、主机仍在运行，以及 Windows 是否允许 Node.js 的专用网络通信；不要关闭防火墙。服务只提供 dist 文件和游戏协议，不公开源目录。Ctrl+C 停止服务；不支持跨电脑迁移主机。短暂断线自动尝试30秒内恢复，关闭页面后重新开页面会建立新身份。

## 双队涂地

首页选择“双队涂地”，可在笔记本工地、折纸街区、画室堡垒三张地图中选择场地，再选职业和画具。单人局是 **2 对 2、4 分钟**：你与一位电脑队友属于蓝墨队，对抗两位朱墨队电脑。电脑通过正式移动、开火、换弹和技能输入参战。倒下5秒自动复活；Esc / P 暂停时，电脑、墨迹和倒计时一并停止。结算后“再涂一局”从干净场地重新开始。单人涂地不写入战役检查点、成长或战绩。

蓝墨队固定使用蓝色，朱墨队固定使用朱橙色，同队不同职业的画具、弹道和技能保持同色。地面被另一队覆盖后，面积归属随之转移。HUD 分别显示两队占**整张可计分地板**的百分比和未染色比例；例如蓝25%、朱35%时，未染色仍是40%。墙面、角色染色和击败数不直接计入面积。四分钟截止后，按最后一帧的实际覆盖面积判胜，平局没有胜者；提前涂到100%也不会提前结束。

配装页的“和朋友局域网对战”进入同规则的真人房间，也可从首页“局域网对战”选择涂地模式。LAN 支持2–8位真人，强制蓝、朱两队且双方都须有人，不自动补电脑；联机菜单不会暂停比赛。房间运行和断线恢复说明见上方启动流程。

## 24 件画具与真实飞弹

四职业各有 **5 件主武器与 1 件近战，共 24 件**，新旧档案均直接开放。配装页展示本职业五张主武器卡片，点击快速选为主武器；下面仍保留主武器、备用武器两个下拉选择，近战随职业自动携带。每局最多携带两件主武器和一件近战。

| 职业 | 本轮新增 | 使用差异 |
|---|---|---|
| 突击 | 双持墨弹手枪、散射卡宾枪 | 一次双发精准点射；五枚聚束墨弹覆盖中近距离。 |
| 重装 | 墨爆火箭筒、转轮机枪 | 两发平直慢火箭与范围爆墨；百发弹鼓、高射速和较大散布。 |
| 游击 | 纸羽连弩、穿甲长钉枪 | 快速半自动、轻微下坠；小弹匣重墨钉贯穿一线目标。 |
| 涂绘 | 泼墨桶、泡泡墨团枪 | 三团低速重力抛墨；缓慢漂行的大墨泡撞击后爆开。 |

所有远程武器现在发射实际飞行的墨弹，移动到碰撞位置后才伤害、染色。弹速、重力、散布、贯穿和爆破由画具决定；画面显示弹体及短尾迹。HUD 显示实际命中伤害，连续命中同一目标会短暂合并数字，击倒有独立确认；角色中弹反应、定向墨滴与冲击圈、武器后坐和倒地后散去共同呈现交火过程。

本地体验建议：按上方步骤构建启动，进入“自由试笔”，用五张卡片和两个槽位轮换新画具，尝试近距离纸靶、远距离提前量与朝地面铺色；再到“双队涂地”比较覆盖效率。新模型有双持双手、火箭筒低位持握、机枪转管、连弩装填箭和泼墨桶前甩动作。开发服务器另提供 `/weapon-review.html` 造型检视及 `/combat-review.html` 真实仿真逐帧检视；这两个页面均不进入生产 `dist`。战斗平衡、音频听感和完整性能仍需人工体验，详见本轮验收边界。

## 自由试笔

按住鼠标右键瞄准，松开退出。普通枪械举枪机瞄；狙击枪打开圆形瞄准镜；弓和绘画工具采用轻度聚焦。换枪、打开菜单、失焦会退出瞄准，换弹期间暂时退出；武士刀右键仍用于格挡。瞄准时鼠标灵敏度随视野缩放。

首页选择“自由试笔”，四职业、24件武器全部开放。纸靶使用正式对战伤害，击倒5秒后重生；Esc 返回装备页，再次开始会恢复干净场地和弹药。练习不写入战役检查点、成长或成绩。三项练习可按任意顺序完成：击倒纸靶3次、染上至少1%的可计分地板、成功释放一次职业技能。完成后仍可继续自由练习。

战役配装页可选择“先做上手试笔”，按实际完成的开火、换弹、换画具、技能和钩索逐项提示，可随时跳过。练习中按 **P** 暂停并保留场地，再继续；**Esc** 仍返回换装并重置。练习与结算提供本地 PNG 留影和干净地图/当前彩墨对照。对照左图是当前地图的留白渲染，不是历史截图。画具设置提供三档实际渲染负载和 100%/120%/140% HUD 字号。

浏览器无法保存时会持续提示并提供“重试保存”，本页可以继续；关闭前请先确认恢复。多窗口保存会合并统计增量和不同的设置改动，检查点冲突先保留外部恢复副本，再保存当前页面检查点。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 / 冲刺 | WASD / Shift |
| 跳跃 | Space |
| 射击 / 蓄力释放 | 左键；弓和钢笔按住左键蓄力，松开攻击 |
| 瞄准 / 格挡 | 右键；狙击开镜，武士刀正面减伤 |
| 换弹 / 切武器 | R / 1、2、3 或滚轮 |
| 职业技能 / 钩索 | E / Q，钩索瞄准空中圆环；单机也能钩拉敌人 |
| 菜单 / 战况与脚下地板归属 | Esc / 按住 Tab |
| 暂停试笔 / 单人涂地 | P 保留场地；试笔 Esc 返回换装会重置，单人涂地 Esc 打开暂停菜单 |
| 结算查看战场 | WASD，Space上升，Ctrl下降，鼠标转向 |

点击画面锁定鼠标；不支持锁定的浏览器可按住画面拖动瞄准。Esc 退出锁定并开菜单。单机菜单暂停，联机比赛继续。

四职业：突击闪步、重装纸盾、游击侦察、涂绘彩墨爆发。每人最多两件本职业主武器和一件近战。蓝、朱队伍的墨色固定，队伍环、标记和战况文字辅助辨认敌我；单机战役与自由试笔使用固定职业墨色。

单机每章两次任务和一次 Boss，共9遭遇。任务后选三选一成长，再按“收好画具 · 继续”。**当前体验版全部24件武器直接开放**：选择职业后，可从该职业五件主武器中选择两件，近战自动携带；补给页也可换装。新旧档案均立即生效，无需完成3/6场遭遇。死亡结束本局，保留挑战、战绩。检查点在遭遇间写入，刷新后从上个检查点重新开始当前遭遇；检查点不保存交火中的弹体与整张墨迹。浏览器本地档案相互独立，清除站点数据会清档。无账号，无云存档，无永久属性提升。

竞技：击杀对抗6分钟（个人20/团队40）；染色占点8分钟或200分（每分钟轮换，地板60%后计分）；双队涂地4分钟截止比面积。角色和墙面染色不计分。死亡5秒复活，可先选职业和装备。结果可观看彩墨战场；局域网房主“再来一局”返回大厅重新准备，单人涂地则“再涂一局”。
