# 墨绘战场

以 Opus 5.5 为主的细铅笔线稿、暖色纸张、少量蓝色标记与持续积累的彩墨。电脑浏览器 FPS，支持单机三章闯关和 2–8 人局域网竞技。原来的两个 Demo 保留在上级目录，新工程独立运行。

最新模型与验收：[武器、人物和怪物优化](docs/MODELS-20261021.md)。前一轮整体设计：[设计记录](docs/DESIGN-20261021.md)。

## 启动

Vercel 发布使用 `npm run build:cloud`，提供单机战役和自由试笔。该构建在局域网页展示启动说明，不连接站点上的 `/ws`。本地构建 `npm run build` 保留完整局域网房间功能。当前房间状态位于独立 Node 服务的内存中，本次不把它迁移成公网房间服务。

安装 Node.js 22.12+（开发验证为 24.14.0），在本目录打开 PowerShell：

```powershell
npm ci
npm run build
npm start
```

浏览器打开 **http://127.0.0.1:8903/**。也可以双击 `启动单机.cmd`（或右键运行 `启动单机.ps1`）；脚本自动检查依赖并构建。不要直接双击 index.html。

开发：`npm run dev`，地址 http://127.0.0.1:8902/。开发服务器只监听本机；连接房间仍需单独启动游戏服务。

局域网主机双击 `启动局域网.cmd`（或运行 `启动局域网.ps1`），也可以：

```powershell
npm run build
npm run start:lan
```

服务输出该电脑的局域网地址，例如 `http://192.168.1.20:8903/`。所有玩家用自己的电脑打开该地址，进入“局域网对战”。房主创建房间并分享房间号，其他玩家填号加入。选择模式/地图/队伍、职业和画具后，每个人点击“确认装备 · 准备”，房主开始。团队模式需要两队都有人，至少两位真人。单机解锁不限制竞技装备。

无法连接时检查同一局域网、地址、主机仍在运行，以及 Windows 是否允许 Node.js 的专用网络通信；不要关闭防火墙。服务只提供 dist 文件和游戏协议，不公开源目录。Ctrl+C 停止服务；不支持跨电脑迁移主机。短暂断线自动尝试30秒内恢复，关闭页面后重新开页面会建立新身份。

## 自由试笔

按住鼠标右键瞄准，松开退出。普通枪械举枪机瞄；狙击枪打开圆形瞄准镜；弓和绘画工具采用轻度聚焦。换枪、打开菜单、失焦会退出瞄准，换弹期间暂时退出；武士刀右键仍用于格挡。瞄准时鼠标灵敏度随视野缩放。

首页选择“自由试笔”，四职业、16件武器全部开放。纸靶使用正式对战伤害，击倒5秒后重生；Esc 返回装备页，再次开始会恢复干净场地和弹药。练习不写入战役检查点、成长或成绩。三项练习可按任意顺序完成：击倒纸靶3次、染上至少1%的可计分地板、成功释放一次职业技能。完成后仍可继续自由练习。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 / 冲刺 | WASD / Shift |
| 跳跃 | Space |
| 射击 / 蓄力释放 | 左键；弓和钢笔按住左键蓄力，松开攻击 |
| 瞄准 / 格挡 | 右键；狙击开镜，武士刀正面减伤 |
| 换弹 / 切武器 | R / 1、2、3 或滚轮 |
| 职业技能 / 钩索 | E / Q，钩索瞄准空中圆环；单机也能钩拉敌人 |
| 菜单 / 战况与脚下地板归属 | Esc / 按住 Tab |
| 结算查看战场 | WASD，Space上升，Ctrl下降，鼠标转向 |

点击画面锁定鼠标；不支持锁定的浏览器可按住画面拖动瞄准。Esc 退出锁定并开菜单。单机菜单暂停，联机比赛继续。

四职业：突击闪步、重装纸盾、游击侦察、涂绘彩墨爆发。每人最多两件本职业主武器和一件近战。颜色只是视觉，敌我看队伍环、标记与战况归属。

单机每章两次任务和一次 Boss，共9遭遇。任务后选三选一成长，再按“收好画具 · 继续”。**当前体验版全部16件武器直接开放**：选择职业后，可从该职业三件主武器中选择两件，近战自动携带；补给页也可换装。新旧档案均立即生效，无需完成3/6场遭遇。死亡结束本局，保留挑战、战绩。检查点在遭遇间写入，刷新后从上个检查点重新开始当前遭遇；检查点不保存交火中的弹体与整张墨迹。浏览器本地档案相互独立，清除站点数据会清档。无账号，无云存档，无永久属性提升。

竞技：击杀对抗6分钟（个人20/团队40）；染色占点8分钟或200分（每分钟轮换，地板60%后计分）；全图涂地4分钟。角色和墙面染色不计分。死亡5秒复活，可先选职业和装备。结果可观看彩墨战场，房主“再来一局”返回大厅重新准备。
