# 2026-10-21 设计完善

延续用户确认的 Opus 5.5 铅笔素描、暖纸、少量蓝色线稿。四职业和16件武器继续全部开放。本轮重点是让玩家更容易读懂场地、装备和交火反馈，保留原有章节与竞技规则。

## 实际落地

| 玩家体验 | 实现 |
|---|---|
| 地图不再只有空白体块 | 工地加入施工图、木箱接缝和尺寸线；街区加入折纸店面、橱窗和颜料摊；堡垒加入画框、风景草稿与墨水标签。插画贴合已有碰撞表面，不能穿行的墙不会画成可通行门。 |
| 目标在场景中可找 | 当前占点更清晰，未激活点减淡；战役染色/守护显示实际任务圆圈，守护画心用非实体投影指示；无关玩法隐藏据点提示。 |
| 素描细节不被冲掉 | 后处理保留表面暗色笔迹的局部对比；墨迹在插画之上累积。武器近景保留少量材质差异，调整长枪持握位置及准星底座连接。 |
| 选择装备有依据 | 选择的主/备用武器显示用途、操作、当前模式基础伤害、弹量、换弹、射程；霰弹按每弹丸标示，蓄力标示满蓄，不虚构DPS。 |
| 战斗反馈可辨 | 真实命中确认、最多3条限时击倒提示、受伤边缘/低血文字、换弹与蓄力进度、Boss真实血条。减少动态设置关闭受伤闪动。 |
| 初次操作有小目标 | 自由试笔提供击倒3次、染色1%、成功释放技能三项并行练习；无需按顺序，完成后继续自由练习，重置清除练习状态。 |
| 声音不再全部相同 | 16件武器按稳定模型ID对应合成音色，另有命中/击倒/技能音；霰弹多射线合并为一次声音；所有资源本地生成。 |

## 模块与资源

- `MapArt` 只创建固定数量的表面插画，不写入物理或计分规则；`ObjectiveView` 消费快照，不自行判定胜负。生命周期由 `WorldView` 统一释放。
- 彩墨与表面插画使用独立纹理，装饰先绘制，保持普通透明物体排序。重开清墨不删除插画。
- `BattleFeedback` 通过真实 `GameFrame` 更新，有界、去重、超时清除；会话更换时重置。
- `PracticeGuide` 通过权威死亡、地板归属与成功技能状态计算进度，练习不写入永久档案。
- `GameAudio` 保留原接口，19个可复用短PCM缓冲，最多12个声部（远端最多8），自然释放。当前协议没有蓄力开始/取消事件，所以没有伪造持续蓄力声音。
- `world-review.html` 是仅开发服务器可访问的场景检查工具，支持地图/目标预览、示例染色、资源重置和真实WebAudio资源检查。示例染色不代表实战成绩，检查工具不进入生产构建。

## 验证与证据

证据目录：`artifacts/design-20261021/`。

- **自动化**：87/87测试通过；新增试笔与UI行为按已确认的公开边界做红→绿；类型检查、生产构建通过。16武器实际输入、伤害、耗弹、换弹与事件检查通过。构建仍有主包超过500kB的提示。
- **浏览器**：1280×720配装页完整可见，选钢笔后说明立即变化；实际试笔完成技能计数、击倒提示/纸靶进度、真实换弹条，换装后恢复0/3。钢笔按住显示满蓄条，松开耗弹并命中；彩墨爆发使染色/技能两项完成，显示2/3。
- **画面**：三地图有独立表面图案；街区开局与示例染色对比、堡垒守护投影已截图。长枪镜头位置经真实试笔检查。
- **场景资源**：十次跨地图切换，同一地图稳定恢复：工地139几何/23纹理、街区147/35、堡垒130/27，程序10。该样本只有场景与目标标记，不等于满房战斗或30分钟性能验收。
- **声音资源**：真实浏览器AudioContext处于running，19缓冲，短时12声部，随后释放至0。音色已做多采样率PCM数值检查；未进行人工听感验收。
- **未宣称完成**：双物理电脑LAN、1080p目标帧率、30分钟连续染色性能、真人三章难度与时长评估。本轮未改变这些验收状态。
