# 暖纸与彩墨：战斗声音设计（2026-10-21）

## 目标与范围

为暖纸、石墨线条和彩色墨迹建立短促、可区分的战斗听觉反馈。声音全部由本地 WebAudio 合成，无素材下载、外部库、语音或音乐。保留 `GameAudio(volume)`、`unlock()`、`event(GameEvent, local)`、`dispose()` 接口。本次未改事件协议、Renderer、第一人称武器、UI、持久墨迹或 CombatEffects。

## 音色安排

| 武器 | 听觉设计意图 |
| --- | --- |
| 步枪 / 冲锋枪 / 卡宾枪 | 短而干燥的宽频击音，冲锋枪更高、更短；步枪保留低频支点；卡宾枪更紧致 |
| 霰弹枪 / 轻机枪 / 榴弹 | 较低的下行音高与纸质气团；霰弹枪散开，轻机枪收短，榴弹为中低频空腔感 |
| 左轮 / 狙击枪 | 左轮短击后带极轻机械回声；狙击枪为清晰起音和较低的短尾 |
| 弓 | 两层衰减谐波与少量摩擦噪声，提示弓弦松放 |
| 铅笔 | 高频带通颗粒与规律细小起伏，模拟石墨划纸 |
| 毛笔 | 较低的柔性噪声和两次下滑音，提示湿墨喷溅 |
| 钢笔 | 从高到低的释放音、低频支撑和渐收的墨流噪声 |
| 武士刀 / 圆规 | 扫频气流，圆规更短、更尖；不在挥空时伪造命中撞击 |
| 重锤 / 滚筒 | 重锤是较慢的低频挥动；滚筒是短段连续滚动的湿纸摩擦 |
| hit / skill / death | 命中短点、技能上扬、击倒下落；不从缺少 weaponId 的事件推测武器 |

这些是合成参数表达的设计意图，尚未经过人工听音验收。

## 实现与边界

- `src/client/audio/Palette.ts` 定义 16 种武器和 3 种事件音色；通过武器 ID 解析内容中的稳定 `model`，再索引音色。未知或缺失武器 ID 不发射击音。
- 首次解锁时，在当前设备采样率下生成并缓存单声道 PCM。每次事件只建立一个 BufferSource 和一个 GainNode；谐波、扫频与滤波噪声已混合进缓冲，避免每发建立多个振荡器。
- 确定性噪声便于检查；事件 ID 提供 ±1.2% 播放速率变化，避免长连射完全机械重复。正常单声部最长约 0.385 秒，无循环播放和持续振荡器。
- 总声部上限 12，远端最多 8，本地可占剩余位置。达到上限时丢弃新到声音，不抢占正在播放的波形。所有本地声部满载时，本地新声音也可能被丢弃；没有承诺每个事件都必然可听。
- 同一 actor、同一武器在 26ms 内的 shot 合并，处理霰弹、喷墨和弹射的多射线事件；命中为 45ms，技能与击倒为 60ms。不同角色互不吞声。网络积压后同时到达的实际连发也可能被合并，现有协议没有独立射击动作序号可供精确分组。
- 本地基础增益 .25、远端 .075，命中再乘 .7；主音量限制到 0–1，非有限值按静音处理。每次事件读取设置，使用 12ms 平滑过渡。没有事件时修改音量不会主动刷新正在播放的短尾，这是保留现有 API 的限制。
- PCM 起止为零，幅度峰值限制为 .85；声部还有 2ms 起音、12ms 收尾，并经主压缩器限制叠加瞬态。它们用于减少点击和叠加过载，不能代替真实输出设备上的听音检查。
- 自然结束后断开 source/gain 并移出集合；dispose 先平滑淡出 12ms，24ms 后释放节点、缓存与上下文。重复 unlock 不重复建立节点，resume/close 拒绝不会产生未处理 Promise；重复 dispose 安全。
- 尚无空间声像、距离衰减、遮挡、混响、装填音或低血量提示。`local` 沿用 Renderer 的事件来源含义，不能据此认定命中接收者就是本地玩家。
- 钢笔和弓目前只有释放时的 shot，事件协议没有蓄力开始、过程或取消通知。因此本次实现的是蓄力武器的释放音，没有按键期间持续升调音，也不伪造蓄力进度。

## 已执行验证

- `npm run typecheck`：通过。
- 纯 PCM 数值检查：44.1kHz、48kHz、96kHz 三种采样率，19 个音色均非静音、样本有限、首尾为零、峰值不超过 .850001，各音色缓冲不同；16 个内容武器均找到音色映射。
- 未建立假 AudioContext 测试，也未进行人工听音、真实设备响度校准或战斗性能验收。真实浏览器 AudioContext 生命周期与密集事件资源检查由主任务进行，结果应单独记录。

建议人工验收：依次试听冲锋枪、霰弹、左轮、弓、铅笔、毛笔、钢笔与四种近战；检查连续喷墨不刺耳、命中不盖过射击、静音与退出无长鸣，再在密集战斗中调整相对响度。
