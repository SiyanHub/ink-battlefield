# 联机可靠性与快照优化 / 2026-10-22

本次保留 60Hz 权威模拟、20Hz 网络状态、2–8 人局域网和 30 秒服务端身份恢复租期，不引入公网服务。

## 已实现

- 收不到新输入超过 500ms，清空该玩家排队输入并释放持续移动、射击、瞄准/格挡和蓄力。100ms 的正常间断仍保持按住动作。释放不伪造输入序号、不增加 ack；蓄力被取消，不把失联当作松开扳机而额外开火。
- 服务端每秒发送 WebSocket ping，超过约 5 秒未收到 pong 主动终止静默连接；连接断开后仍保留原 30 秒重连身份。浏览器协议自动回应 pong，兼容正常旧客户端。
- 客户端每秒发送应用 ping，并监测所有收到的应用消息。约 5 秒静默时主动开始恢复，不依赖浏览器最终发出 close。停止预测并丢弃失联前的输入积压，完整权威状态恢复后重新采样。
- 客户端恢复窗口保持 29 秒，以留出服务端租期余量；每次握手等待也受剩余窗口约束。超时给出终止提示，并清理看门狗和重试。原连接尚未被服务端判定断开的竞态用 `resume_pending` 区分，不提前当作凭证失效；真正过期和重复身份权限保护保留。
- `Simulation.getSnapshot(false)` / `takeFrame(false)` 直接略过完整墨迹快照生成。普通网络帧走此路径；首次开局与重连仍传完整墨迹，默认本地会话接口不变。
- 网络客户端按受影响表面复制墨迹；无染色变化直接复用旧墨迹快照，同帧同表面事件合并处理一次。旧公开快照不会被后续增量、预测或完整同步修改；新比赛清空旧状态。
