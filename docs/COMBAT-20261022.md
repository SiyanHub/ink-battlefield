本轮在双队涂地版本上扩充装备选择，并把远程射击改为可见、实际飞行的墨弹；命中、伤害、涂色与画面碰撞使用同一仿真结果。本轮只交付本地工程，**没有提交、推送或部署**。README 中的在线站点仍是此前发布版本。

## 正式交火规则

- 普通枪、点射、散射、喷墨和贯穿武器统一发射真实弹体。触发开火只消耗弹药并生成弹体，移动到碰撞处才应用伤害或墨迹；霰弹每次扳机仍只有一次开火反馈。
- 弹速、重力、射程、爆破与贯穿取各画具定义；弹体半径控制可视体积，碰撞沿中心轨迹检测共享角色命中体积。高速弹体沿整段位移检测碰撞，墙体会阻挡；贯穿墨弹按命中预算穿过敌人，每个目标只受一次该弹体的伤害。近战仍按原近身规则处理。
- 涂地截止只接纳截止前实际到达的墨迹；未到达的弹体不能把未来碰撞倒算进最终面积。已发出的弹体可在射手倒下后完成其飞行和命中。
- 原有 `hitscan`、`beam` 等行为ID保留以兼容内容注册；名称不再表示即时远距离伤害。具体薄墙、队友阻挡、穿透及伤害边界以公开 Simulation 回归为准。

高速弱点命中判定已按实际碰撞点修正，三档弹速得到一致伤害。LAN两次快照之间已经生成又结束的短命弹体，通过权威出生/结束事件补齐；客户端按弹体ID呈现75ms短实体，避免漏显、重复显示或被迟到快照复活，不追加伤害。真实WebSocket与表现回归均已纳入最终267项检查。

## 开火、受击与倒地表现

画面中的远程弹道由实际弹体和短尾迹构成，不再用枪口直连终点的长线代替飞行；钩索保留连接线。普通墨弹、针状弹、火箭和大墨团有不同体积和形状。命中法向驱动滴溅与冲击圈，持续地面墨迹仍由 PaintView 管理。瞬态粒子、纸屑、冲击圈与弹体采用容量上限和复用，切图/重开会清理。

HUD使用权威命中事件的实际伤害数字，同一目标短时间内的多次命中合并显示；击倒使用不同确认样式。范围伤害同时击中其他存活目标时，该目标的数字仍标“命中”，不会被另一目标的死亡误标为“击倒”；独立击倒提示保留，回归已覆盖。武器有差异化后坐、双持双枪口、转管起停、连弩装填箭和桶的抛洒动作；中弹角色有短时受击反应。首次及低帧率情况下的枪口脉冲等到首个呈现帧再开始，避免事件到达后还未显示就已过期，相应回归已通过。

死亡在规则侧立即生效，角色停止行动；渲染侧短暂保留完整模型倒地，然后展开纸片散去并释放。死亡事件、死亡快照和后续复活分开处理，防止旧快照使刚倒下的角色闪回；更换会话与地图时清除残留表现。该流程是程序化动画，不是布娃娃物理。

24画具声音及受伤、击中、落墨、死亡通路已接入本地 WebAudio，沿用声音源上限、短包络和距离衰减。自动检查声音参数不等于真实聆听，本轮尚未人工确认音色满意度或连续交火混音。

## 本地体验与检视

普通体验：`npm run build` 后运行 `npm start`，打开服务输出的本地地址，在“自由试笔”选择新画具；也可进入单机战役、单人电脑双队涂地或本地局域网房间。战役检查点仍只保存遭遇间状态，练习与单人涂地不新增战役存档写入。

开发检视：运行 `npm run dev`，打开开发地址下的 `/weapon-review.html` 或 `/combat-review.html`。造型页动态排列24件模型，并可切第一人称及动作；交火页使用正式仿真，通过停止点和逐帧推进查看弹体、首次碰撞及死亡过程。这些独立检视页面**不进入生产 `dist`**，不能当作正式网页的新入口。
