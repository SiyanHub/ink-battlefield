# 渲染、预警与战场留影优化

日期：2026-10-22。保留暖纸、铅笔排线和少量蓝线，未更改武器伤害、地图碰撞或墨迹计分。本记录区分已实现、自动化证据与待实机验收。

## 已实现

- **实际画质分档**：DPR=1 时，轻量/均衡/细腻的内部像素比为 0.72/1/1.15；统一上限 1.5。法线缓冲分别使用对应画面尺寸的 0.5/0.75/1 倍。轻量关闭动态阴影，均衡采用 768 阴影贴图、细腻 1024。DOM 菜单与 HUD 不参与降分辨率，原有鼠标坐标与摄像机宽高比保持一致。档位切换释放旧阴影贴图，避免留下无用 GPU 资源。
- **按楼层显示预警**：圆形范围以共享 `World.ray` 查询实际支撑面，起点在角色脚下或权威落点附近，避免误投射到头顶平台。俯冲使用规则层已锁定的 `GameEvent.pos`；横扫/震地以施术者脚下为中心。冲锋范围沿路径分段贴地，找不到表面时不虚构地板。预警圆圈作为透明覆盖层，不进入法线场景的实体轮廓计算。
- **第一人称笔触和角色可读性**：近景继续采用独立视角渲染，不新增昂贵的第二套后处理。`WeaponPaper` 增加两向、随明暗变化的细排线和轻微纸纤维，保留深色握把、五金与纸色差异；接缝线略加深。角色轮廓与基础明度轻微加强，保持职业衣装与染色逻辑。
- **试笔钩索指引**：只在自由试笔显示最近、30 米内且无遮挡的真实锚点，使用稍大的蓝灰圆环和“Q 钩索练习”文字。成功钩索后隐藏，重开恢复；正式战役和竞技不显示这条教学标签。
- **本地战场留影**：`Renderer.captureBattlefield(snapshot, { compare?: boolean }): Promise<Blob>` 生成 PNG。单张为 1440×1008，对照为 2880×1008。统一鸟瞰构图覆盖三张地图的完整可玩地板；对照图使用同一相机、同一纸纹时刻，只切换墨迹可见性，分别标记“开局 · 留白画页”和“本局 · 彩墨战场”。角色、武器、临时特效、任务和教学标记不入画。这里的开局是当前地图的干净对照，不伪造开局截图或修改墨迹/比分。

## 留影资源与恢复

同步完成渲染并立即复制到独立 2D Canvas，之后才异步编码 PNG；无需常驻 `preserveDrawingBuffer`。鸟瞰时暂时关闭第一人称距离雾，并延后轮廓淡出距离，防止高位取景把整张地图洗白。`finally` 恢复摄像机、雾、对象可见性、内部渲染尺寸及实际画面，不改变会话快照或存档。全部像素在本地处理，接口不访问网络。UI 负责用户触发和 Blob 下载。若请求快照属于其他地图则明确报错，避免为了截图切换玩家场景。

## 自动化证据

新增 `tests/render-improvements.test.ts`，2026-10-22 本地执行 `node --import tsx --test tests/render-improvements.test.ts` 为 **5/5 通过**：

1. DPR=1 的三档负载确实不同，DPR=4 仍受像素上限约束。
2. 上层平台和下层空间的预警落在各自支撑面，场外没有虚构落点。
3. 对照捕获的两个视图共享同一相机；正常结束或中途抛错均恢复原相机与可见性。
4. 钩索提示排除被墙遮挡和超过真实距离的锚点。
5. 三地图四个地板角点投影均留在画幅内，保留边距。

以上行为均先加入测试观察失败，再实现通过。第 5 项首次指出原取景参数裁掉近处角点（归一化 Y=-1.097），调整取景高度后通过。额外运行既有墨迹光栅测试后合计 7/7 通过；随后 `npm run typecheck` 通过。纯材质美术调整不写字符串镜像测试，需通过浏览器画面检查。

## 待验收边界

单元测试不证明 shader 视觉效果、真实 PNG 像素或游戏帧率。子代理的内置浏览器入口返回 `Browser is not available: iab`，未用旧截图冒充本轮画面。主代理将用已有浏览器会话复核：三档实际画面、武器笔触、试笔钩索提示、PNG 解码/内容以及留影后继续操作。全局类型检查和完整测试以本轮总验收为准，开发中曾被其他并行功能尚未接完的类型声明阻挡。

当前没有补做 30 分钟真实前台压力运行、最低配置测试、双物理电脑 LAN 或所有武器逐项人工手感验收；不引用 9 月性能数字作为现版结论。没有为此次改动引入实例化/合批或墨迹 GPU 分块上传，后续应先测量再决定。
