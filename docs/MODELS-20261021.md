# 武器、人物与怪物模型优化

日期：2026-10-21。延续 Opus 5.5 方向的暖纸、铅笔轮廓、排线及少量蓝色标记。此次模型已接入正式游戏，所有 16 件武器保持开放。

## 实际改动

- 武器：重做机匣、护木、枪托与握把的连接关系，区分短冲锋枪、木托卡宾、弹箱机枪、泵动霰弹、左轮与狙击枪。弓臂改薄片反曲形，毛笔改连续笔毫，钢笔收窄笔尖，圆规改扁平双腿，滚筒采用连续弯管。逐件说明见 [武器记录](MODELS-WEAPONS-20261021.md)。
- 第一人称：所有工具都有握持手；非弓副手袖筒从画面左下斜向接入护木。掌心读取模型握持锚点，装弹和蓄力保留原有动作接口。
- 四职业：连续躯干、较小纸面头部、脸部线条、关节与鞋靴。突击使用短盔及弹袋，重装使用胸甲、肩甲及面罩，游击使用兜帽和披肩，涂绘使用贝雷帽、围裙与画笔口袋。
- 六类怪物和三位 Boss：面具、冲锋折翼、重甲、墨罐和不同衣装分别构成轮廓。飞行单位使用折纸翅翼、尖身、尾片与收起的爪足；巨像增加背部纸叠，巨匠使用长袍与冠形纸片。
- 动作：腿部有髋与膝关节；双臂通过两段关节到达主手/副手锚点。攻击、受击、抬枪与近战挥击消费正式事件。翼面有持续扇动。
- 模块：`models.ts` 保留公开入口，细节拆入 `actors/PaperParts.ts`、`Costume.ts`、`PaperRig.ts`；`ActorView` 管理持械、事件和资源释放。

## 命中与兼容

头部缩小同步更新共享 `actorGeometry`；Boss 的头部随身高变化，不再被肩宽横向放大。新增两个公开 Simulation 测试，先验证旧版本会误中头顶上方射线，再最小修改使其通过。精确头部相交优先于粗略躯干球体，保留既有大型敌人弱点回归。

身体仍使用既有近似命中体，衣装、冠饰和翅翼不是额外伤害区域。此次没有把命中改成逐三角形碰撞，也没有改动武器数值、单机成长或联机协议。
