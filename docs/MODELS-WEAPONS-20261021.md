# 武器模型第三轮：轮廓、结构与握持

日期：2026-10-21。仅覆盖 `src/client/weapons.ts`、`src/client/weapon-view.ts`、`src/client/render/WeaponPaper.ts`。

## 设计取舍

延续暖纸、细铅笔轮廓和少量蓝灰标记。通过实际几何、连续连接与明暗层级改进识别，不依赖换色或添加悬空装饰块。共享场景材质和游戏规则不变。

| 武器 | 本轮模型变化 |
| --- | --- |
| 突击步枪 | 收紧机匣肩部与握把轮廓，护木接入机匣，保留弯弹匣；加入低对比接缝线 |
| 冲锋枪 | 短机匣、短直弹匣与双杆伸缩托形成独立轮廓 |
| 卡宾枪 | 短木托、木护木、短弹匣；不再只靠枪管长度区分 |
| 轻机枪 | 宽弹箱采用折角截面，顶部供弹盖与机匣连续，前托位置避开弹箱 |
| 霰弹枪 | 泵动护木改圆截面与细防滑环，沿双管轴线移动 |
| 左轮 | 保留可动弹巢，握把增加嵌片与弧形轮廓 |
| 狙击枪 | 连续木枪床、贴面线条与扳机护圈；保留镜筒与拉栓 |
| 榴弹发射器 | 机匣肩部收角，粗枪管下增加接合前护木，握持避开弹巢 |
| 铅笔 | 保留连续六角笔杆、木削面、石墨、箍与橡皮，杆上印记改细线 |
| 毛笔 | 笔毫采用连续渐尖曲面，去掉叠套的彩色圆锥，沿曲面绘制毫线 |
| 钢笔 | 笔身变细，握位渐收，金属笔尖增加肩部和刻线，笔夹与尾帽连续 |
| 武士刀 | 环状握柄纹改成交叉缠线，增加低对比刃纹；支持双手握柄 |
| 铅笔重锤 | 加强手柄插入锤头的套接部位与尾端封口，支持双手握持 |
| 圆规 | 圆杆双腿改成有厚度的扁平腿，保留螺杆、铰链与针尖夹套 |
| 弓 | 圆管弓臂改薄片反曲轮廓，弦、箭与拉弦动画继续工作 |
| 滚筒 | 三段直角杆改成连续弯管，手柄套口、滚芯与端盖保持完整连接 |

## 握持接口

`buildWeapon` 返回的 `THREE.Group` 保持原接口和工作方向 `-Z`。锚点是武器本地坐标，随根模型一起变换：

- 每件武器都有 `getObjectByName("grip-anchor")`，其 position 是主手掌心握持位置。
- 需要副手的模型有 `getObjectByName("support-anchor")`：步枪、冲锋枪、卡宾、机枪、霰弹、狙击、榴弹、武士刀、重锤、弓。
- 左轮、三支笔、圆规、滚筒没有副手锚点。
- 同时提供 `root.userData.gripAnchor` 和可选 `root.userData.supportAnchor`，值为 `[x, y, z]` 数组。优先使用 Object3D 接口转换到世界坐标。
- 原有 `muzzle`、`magazine`、`cylinder`、`pump`、`bowstring`、`arrow`、`roller` 名称保留，现有动画可继续访问。

第一人称直接读取这组锚点，不再维护另一套不一致的手部位置。所有工具显示握持手；四指使用连续曲线包住握位，拇指与掌心方向分明。前臂从腕部逐渐加宽到画面下沿，带袖口和一条缝线；装弹、泵动与拉弓时继续跟随手部。

## 材质

武器内部材质保留纸白、木色、灰硬件、深石墨四档明暗，而不修改共享 `primitives.ts`。`WeaponPaper` 的 v3 shader 保留源光照亮度，纸色调只参与色相混合；避免旧版归一化后白机匣和深色握把都落在同一档灰色。阴影铅笔斜线保持轻量。

## 验证与资源

- `npm run typecheck` 通过。
- 在 Node/Three.js 下实际创建全部 16 个模型与 WeaponView，各推进 30 个动画帧，覆盖装弹阶段、移动和蓄力状态；无运行异常。
- 16 个模型全部读到主手锚点；10 个模型读到副手锚点。
- 武器本体为每件 4–27 个 Mesh、289–1,864 个顶点（不含第一人称手臂与独立轮廓线）。模型尺寸检查未发现非有限值。
- 新增手/袖每只约 9 个 Mesh；三支笔等原本不显示手的工具增加此部分开销。毛笔曲面和细线替换原本的独立笔毫杆，弓臂改薄片后均减少本体几何量。
- 没有下载素材、图片纹理、贴图、网络请求、额外渲染目标或新依赖。沿用既有模型替换时的 dispose 生命周期。
- 浏览器内最终外观、准星遮挡、运动观感由主任务统一验收；上述静态与运行检查不等同于视觉验收。
