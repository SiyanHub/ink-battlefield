# UI / 会话生命周期重构交付记录

## 改动文件

- `src/client/app.ts`：从 584 行混合职责类变为浏览器组合根。只负责 DOM、输入、渲染器和逐帧同步；退出/暂停时释放输入，菜单隐藏战斗 HUD，恢复同类操作按钮的键盘焦点，通知超时归一。
- `src/client/ui/controller.ts`：可无浏览器运行的公开 GameController。集中拥有会话订阅、启动/销毁、导航、存档入口、联机房间与过期异步连接保护；断开旧会话前取消订阅。试笔 Esc 返回装备选择并销毁旧计时会话；再次开始生成干净场地，保留选择。取消载入后不会悄悄启动后台会话。
- `src/client/ui/views.ts`：纯页面视图，保留首页/职业/联机/房间/成长/死亡换装/暂停/设置/档案/结果/观察入口。
- `src/client/ui/components.ts`：共享的安全文字转义、按钮、职业素描图标、装备选择与操作说明。
- `src/client/ui/hud.ts`：独立紧凑战斗 HUD。常驻任务、生命、弹药、技能与装备；完整操作放在 Tab/暂停页，降低中心遮挡。
- `src/client/style.css`：替换原满蓝线 UI。石墨灰文字、暖纸底色、少量蓝色选中态；中文信息层级、紧凑描边菜单与职业卡，窄屏/矮屏布局、焦点轮廓、减少动画偏好。
- `tests/ui.test.ts`：原房间控件回归从 App.prototype 的内部伪对象改到公开 GameController + renderMenu 边界，验证内容保留。
- `tests/ui-flow.test.ts`：新增自由试笔入口/全武器/档案保护、Esc 销毁和重新启动、续档暂停与设置恢复、取消载入四项公开行为测试。
