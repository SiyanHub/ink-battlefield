# 墨绘战场 · 实施基准

版本：首版 / 2026-09-26。本文记录用户已批准的范围，验收证据另见 ACCEPTANCE.md。功能存在不等于全部验收通过。

## 体验与平台

在电脑浏览器使用键盘鼠标，中文界面。独立目录保留两个原 Demo，不复制其环境变量、部署或账号配置。沿用射击 Demo 的暖纸、蓝色圆珠笔线稿、排线和机动射击，融合水墨 Demo 的多色飞溅。玩家打完一局，地图成为一张彩画。

静态地板、墙面和建筑的墨迹持续到本局结束；角色可被染色。短暂粒子独立回收。视觉颜色与地板归属分开；颜色没有元素伤害。结算可观看战场，下局清空。地板计分，墙和角色不计分，不同楼层分开。

## 内容与控制

四职业初始开放；每人两主武器槽、一近战、一职业技能。冲刺、跳跃、锚点钩索保留；单机可钩拉敌人，竞技仅用于机动。单机和竞技伤害独立；竞技连续有效命中约一秒击倒是待实玩的平衡目标。

| 职业 | 主武器 | 近战 | E 技能 |
|---|---|---|---|
| 突击 | 突击步枪、冲锋枪、连发卡宾枪 | 武士刀 | 闪步 |
| 重装 | 霰弹枪、轻机枪、榴弹发射器 | 铅笔重锤 | 正面纸盾 |
| 游击 | 左轮、狙击枪、蓄力弓 | 圆规双刃 | 侦察脉冲 |
| 涂绘 | 铅笔连射器、毛笔喷墨器、钢笔蓄力炮 | 涂墨滚筒 | 范围彩墨爆发 |

16 件武器必须具备实际节奏、弹道或范围、装填、涂染和表现差异，换名换色不算新武器。职业需要不同外形、持械和技能反馈。

## 单机

目标一局20–30分钟，三个章节：笔记本工地、折纸街区、画室堡垒。每章两个清剿/地板染色/守护任务，再打一位 Boss。六类普通敌人：近战、冲锋、重装、射手、涂绘、折纸飞行。三 Boss 分别侧重冲击近战、俯冲弹幕、召唤控场，均有预警和阶段变化。

遭遇后提供三选一升级、补给和换装。30项升级为18通用+每职业3专属。初始只有一件主武器和近战；每职业累计完成3/6次遭遇解锁另外两件主武器，第二槽随解锁可用。永久档案保存设置、解锁、挑战/统计；不永久增加属性。遭遇之间保存检查点；死亡结束本局，清除本局成长与检查点，但保留解锁和成绩，可重新选职业。

## 局域网竞技

2–8真人，无机器人。全部职业武器公平开放。房间包含昵称、模式地图、分队、准备、开始、结果和重赛。至少两人，团队关闭友伤；平局明确显示。死亡可换职业装备，5秒复活；出生保护在攻击时解除。局内不可活着换职业。Esc仅打开个人菜单，比赛继续。断线保留席位30秒并支持重连；主机服务停止则结束会话，不迁移主机。

| 模式 | 胜负与默认值 |
|---|---|
| 击杀对抗 | FFA或两队，6分钟；个人20或团队40提前结束 |
| 染色占点 | 三点每60秒轮换；当前点可计分地板达到60%开始得分；200分或8分钟 |
| 全图涂地 | 两队，4分钟比较全图有效地板面积比例 |

## 工程边界

TypeScript、Three.js、Vite；Node HTTP + ws；浏览器原生WebSocket。共享规则不依赖DOM、WebGL。客户端与服务端使用相同地图几何；服务端判定移动、碰撞、命中、技能、染色和胜负，绝不信任客户端上传的伤害/得分。固定模拟60Hz、网络状态20Hz，移动预测校正、远端插值。有界表面网格保存颜色和归属，快照支持重连/后来加入者。

公开接口包括 GameSession、GameSnapshot、GameEvent、WeaponDefinition/WeaponBehavior、ClassDefinition、EnemyDefinition、UpgradeDefinition、ModeRules、MapDefinition、ProfileStore。入口仅装配，规则、内容、场景、会话、界面存档分层。添加内容通过定义/行为/注册，不改主循环。资源字体本地打包，开发与局域网启动分开，局域网只公开构建产物和游戏协议。

不含公网匹配、账号、合作闯关、外部模组加载器、可视化编辑器。

## 验收

每个功能切片按失败测试→实现→回归推进，围绕战斗模式、真实网络协议、存档和玩家界面四个公开边界。验证职业限制、遮挡、节奏、冷却、死亡换职、地板面积/楼层/比分、非法输入、重复消息、八连接同步、复活重连、版本和损坏档案，以及全部用户流程。

扩展示例接入一把武器和一种规则，证明无需修改主循环。视觉对比开局/中段/结果，验证暖纸蓝线和彩墨持续积累。内容要求三章、三模式、四职业、16武器、30升级实际接入。记录1080p中画质硬件与帧率、持续染色30分钟和重复重开资源上限。八个本机协议连接不等于两台局域网电脑验证；后者必须独立记录。最终类型检查、构建和适用回归通过。原射击 Demo 的68测试为参考基线。
