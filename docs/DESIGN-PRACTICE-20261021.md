# 自由试笔：三项真实练习

## 玩家体验

自由试笔保留无计时、无输赢、真实伤害和真实弹药的沙盒。进入后立即显示「自由试笔 · 三项练习」，以 0/3 到 3/3 表达完成数量：

- 左键击倒纸靶三次。同一纸靶复生后再次击倒也有效，不要求一次击倒三个不同种类。
- 将至少 1% 的可计分地板染成自己的颜色。墙面、遮挡下不可计分网格不计入。
- 按 E 成功释放一次当前职业技能。

三项顺序不限，提前使用技能或先涂地都会保留。说明文字持续列出未完成动作，纸靶显示 0/3 至 2/3，染色显示已覆盖百分比。覆盖率向下保留一位小数，避免尚未达到阈值却显示 1.0%。完成后提示可以继续自由试笔，并说明 Esc 暂停菜单可以重置场地与补给。不会跳转结算或写入档案。

## 判定与生命周期

`ModeState.practice` 持有本局里程碑，独立于共享序列化协议。现有 `snapshot.objective` 的 title、description、progress、target 四个字段足够呈现引导。target 固定为 3。

击倒来自正式伤害系统的死亡回调，只统计练习玩家造成的纸靶死亡。技能完成来自技能成功执行后写入的冷却时间，不检查按键布尔值。地板覆盖率使用正式 `PaintField.coverage()`，按练习玩家的 teamId 读取，达到阈值后锁定完成。

练习模式每个模拟步更新引导，以便技能或击倒立即反馈。地板面积只在首次更新或产生新的 paint 事件时重算，空闲帧不会反复遍历地板。引导在帧事件被 UI 消费前更新，因此发布事件不丢进度。其他模式仍保持原有每秒更新频率。

暂停会停止模拟步，输入尚未执行时不计为完成。重置场地或更换武器创建新的 Simulation，因此三项进度一并清零；暂停状态按原有行为保持。每个会话拥有自己的 ModeState，无跨会话共享进度。

纸靶继续使用原有正常生命值、固定位置与面向玩家出生点的朝向，死亡五秒后原位复生。没有修改伤害、弹药、职业技能、竞技计分或战役注册。

## 验证证据

已在批准的公开 `PracticeSession` / `Simulation` 输入与快照边界完成两轮红→绿：

1. 新测试首先因初始 target=0 而失败；实现三项引导及成功技能判定后通过。涵盖暂停中按键不推进、恢复后成功释放及冷却结束后仍保留完成状态。
2. 新测试首先因真实地板射击后 progress=0 而失败；实现地板覆盖与真实击倒累计后通过。小型可计分测试场地使用正式步枪射击地板、三次击倒复生纸靶，再成功释放技能，最后继续运行三十秒并确认无结算。

附加行为回归覆盖：墙面染色不计为地板完成、两会话隔离、暂停重置清零、更换武器清零。既有真实弹药消耗、五秒复生、朝向、暂停和销毁测试继续保留。定向命令 `node --import tsx --test tests/practice.test.ts`：8/8 通过。
