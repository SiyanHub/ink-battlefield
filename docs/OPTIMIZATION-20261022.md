# 体验优化与验收 · 2026-10-22

本轮按用户确认落实项目审查中的八类改进。保留 Opus 铅笔线稿、暖纸与少量蓝线，四职业、16 画具全部开放。本轮仅修改本地工作区，没有提交、推送或部署；线上仍是此前版本。修改前基线备份位于上级目录 `墨绘战场_体验优化前_20261022.zip`。

## 玩家能够体验到的变化

1. **成长选择有效**：过滤职业永远无法使用的成长，补给页标明当前受益画具，或明确换装后才生效。
2. **任务信息准确**：清剿按击败数量显示进度，显示波次与剩余纸兵；染色显示覆盖与清敌双条件；只在有规则意义的任务显示倒计时。Boss 预警使用实际楼层和锁定落点。
3. **存档故障可恢复**：写入失败后持续显示未保存状态并提供重试，本页保留进度；损坏档案先备份再替换。多窗口采用基线合并：设置只覆盖本窗口改变的字段，统计按增量合并；双方检查点冲突先保存外部副本再保留当前页面检查点。读盘或备份失败均拒绝覆盖。此机制不声称 localStorage 具有跨进程原子事务；极端同时写入仍需要后续事务存储方案。
4. **降低实际开销**：三档画质调整内部像素、法线缓冲和阴影；输入与渲染直接读取缓存设置；网络帧省略整张墨迹快照生成，客户端按表面复制增量。未根据无效帧率样本盲目做大规模合批重写。
5. **战斗节奏与敌人区别**：清剿清场后 2.5 秒可提前下一波；冲锋兵有蓄势、固定方向冲刺和后摇，射手近身后撤，涂绘师争夺任务区。
6. **画面和信息可读性**：近景武器增加细排线和纸纤维，角色轮廓加强；HUD 小字增大，设置提供 100%/120%/140% 字号。
7. **可选上手与留影**：战役配装可直接开局，也可先练习五项操作。引导按真实完成行为计数。练习按 P 暂停并保留场地，Esc 仍返回换装并重置。练习/结算支持本地 PNG 和留白/当前彩墨对照；左图是当前地图的干净渲染，不是历史截图。导出不上传、不改变比分和存档。
8. **弱连接恢复**：500ms 输入超时释放移动/开火/蓄力；约 5 秒静默连接检测，保持原身份恢复窗口；恢复后采用完整权威状态，丢弃失联前的预测积压。

## 性能验收与剩余边界

真实 Chrome 压力采样中，页面报告 visible，但 rAF 仍呈约 1000ms 的间隔。23.2 秒墙钟只执行约 1.92 秒模拟，检测器标记 `valid:false`，因此停止并保留原始无效记录。这个样本不能归因为游戏真实性能，也不能用于声称 FPS 优化已经验收。需要在无环境限帧的前台窗口复测。

尚未完成：有效前台 30 分钟 WebGL 压力、两台物理电脑的 LAN/无线断线体验、真人三章难度与 20–30 分钟节奏，以及所有画具逐项人工手感验收。规则、构建和本机 WebSocket 通过不替代这些结果。
