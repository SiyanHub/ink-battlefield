# 玩法与规则优化 · 2026-10-22

本轮保留四职业、16件画具全开放、三章九遭遇与局域网规则。改动集中于奖励有效性、任务信息和普通敌人的行动差异。

## 已实现

- **成长适用性**：奖励池同时检查职业内是否存在兼容武器。涂绘不再抽到只对 hitscan 生效的「穿透纸面」「折线笔触」。武器要求统一定义在 `content/upgrades.ts`，界面可调用同一 `upgradeAppliesToWeapon` 显示适用装备；不限制当前暂未携带但该职业能够换装使用的成长。
- **任务信息**：Boss、清剿和染色任务不显示没有胜负意义的倒计时；守护保留计时。清剿/守护进度改为已击败纸兵数量，描述同时显示已出场波数与剩余纸兵；染色同时显示画心覆盖阈值和敌人数。
- **清剿节奏**：普通清剿在当前敌人全部击败后休息2.5秒即可提前下一波。守护、染色和显式传入 `duration/groups` 的场景保留原定刷波时序；旧遭遇测试配置契约不变。
- **冲锋兵**：0.6秒蓄势、0.42秒固定方向冲刺、0.75秒后摇。移动仍经过共享碰撞，单次冲刺最多伤害一次，基础伤害不增加。
- **射手**：玩家进入6米内时尝试后退；退路必须有接近当前高度的可站立地板且不被墙体阻塞，再交给已有移动/碰撞逻辑执行。
- **涂绘师**：远处玩家不再吸引它离开任务区，优先前往画心/据点附近持续涂地；玩家进入4米内时恢复近距离应对。
- **俯冲落点**：生成预警时锁定真实地板落点，将该位置作为 telegraph 事件输出；攻击使用同一锁定楼层。屋顶不再以角色腰部高度或零高度代替落点。预警绘制由 `ThreatView` 处理。

## 验证

新文件 `tests/gameplay-improvements.test.ts` 通过公开 `Simulation`、输入、命令、快照和事件验证，不调用内部 AI/导演辅助函数。

1. 原始代码下，涂绘 seed=1 实际射击完成遭遇得到 `damage,supply,pierce`，无效成长测试失败；修复后24个种子通过。突击仍能实际选择穿透成长，接续后一次步枪射击命中两个前后排列目标。
2. Boss测试从 `132 !== 0` 失败转绿；清剿击杀计数、染色双条件、快速清场下一波分别先失败后通过。显式时序及守护回归保留通过。
3. 冲锋预警/后摇、射手后撤、涂绘争点、屋顶落点四项先失败后通过。屋顶预警从原来的5.2米改为实际4.2米，后续俯冲在同一水平落点执行。

## 待实玩边界

这些验证证明规则行为、命中/伤害和既有可达性回归，不替代真实玩家的新手体验、三章难度或20–30分钟时长验收。冲锋兵/射手/涂绘师的动作辨识与新节奏应在最终集成画面中继续复核。
